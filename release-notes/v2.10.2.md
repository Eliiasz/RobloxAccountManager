## 🛠️ What's new in v2.10.2

### 📊 RAM and CPU now match Task Manager, live
• **Live like Task Manager:** the "RAM · CPU" line next to Account List now updates **every second**, like Task Manager. Before, it updated every 2 seconds.
• **CPU matches Task Manager:** it was already the whole PC's CPU, but it used a different measurement that reads lower at light load (for example 0% while Task Manager showed 6%). It now reads Windows' **"Processor Utility"** counter, the same one Task Manager uses on Windows 10/11, so the numbers line up.
• **No more 0% at startup:** the first number appears right away.
• **RAM** uses Task Manager's "in use" calculation (total minus available memory), the same as Task Manager's Memory %.
• It's very light: each reading takes well under a millisecond, and the Roblox window count keeps its own separate timer.
• If a PC can't provide that Windows counter, the app quietly uses the previous CPU reading instead.

### ⚡ Updating
• Coming from v2.10.1, the app downloads a **small patch** and installs it automatically.
