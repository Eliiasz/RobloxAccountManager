## What's new in 2.8.0

**ANAne's Roblox Account Manager**
- New name and logo; the app file is now `ANaneRAM.exe`
- **Contact Us** page (Discord; Telegram coming soon)

**Accounts**
- **Quick Sign-in** button: opens Roblox login and starts Quick Sign-in for you, just enter the code on your phone
- **Account Creator**: set how many accounts and a wait time between each, choose numbers or letters after your prefix
- **Brave** added as a browser option

**Launching**
- Launch Delay **0** now opens all selected accounts at the same time
- **Batch Queue** (Multi Roblox page): open big selections a few at a time; the next batch opens automatically when the current one is closed, with Pause / Resume
- A Roblox "not a bot" check on one account no longer stops the other accounts from launching

**Tools**
- **Kill All Roblox**: instant, no confirmation, plus an optional shortcut key with an ON/OFF switch
- **Ban Check**: finds banned, terminated, locked and "needs verification" accounts (8 at a time) and deletes the ones you tick
- **RAM usage** per running account, optional % and total (Settings → General)
- **Proxy** (Settings → Proxy): ON/OFF button with ping, manual entry, every common proxy format, timed rotation

**Fixes**
- Less freezing with many Roblox windows open
- Clearer buttons and labels throughout
