## 🛠️ What's new in v2.9.9

### ✨ No more flash when the app opens
• Fixed the small **see-through rounded box** that flashed on screen for a split second while the account list loaded.
• The cause: each account's note and 🔒 lock label was briefly created as its own tiny window before being placed in its row. Those labels are now created inside the row, so nothing pops up anymore.
• The rest of the app was checked for the same mistake. No other spots had it.

### 🧩 Background helper starts cleanly
• The small background helper that finds Roblox log files (used by Auto Rejoin and the launch checks) now starts with a **clean environment**, the same way the updater already does.
• This prevents "Failed to load Python DLL"-style error popups from the helper on some PCs.
• If the helper ever fails or times out, a warning now shows in the Console page so the problem can be traced.

### ⚡ Updating
• Coming from v2.9.8, the app downloads a **small patch** instead of the whole exe. If the patch can't be used, it falls back to the full download automatically.
