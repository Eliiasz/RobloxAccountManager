## 🛠️ What's new in v2.10.0

### 🛡️ No more "Installer encountered a critical error"
New setting, **on by default**: Settings → Roblox → **Prevent Roblox installer errors while Roblox is open**.
• **Why it happened:** every launch went through Roblox's own launcher, which checks for an update and tries to install it. With other Roblox windows open, or many accounts starting at once, its files are in use and it crashes with that error box.
• **Now:** while a Roblox window is already open, new accounts start with the Roblox version that's already running, so the updater never runs and can't interrupt your open games. If that ever fails, the app falls back to the normal launcher by itself.
• **Error boxes close themselves:** if a Roblox error box still appears after a launch, it's closed within about a second, instead of only during the Batch Queue.
• **Roblox updates:** when you launch several accounts with no Roblox open and Roblox has released an update, the first account opens alone, the update installs, then the rest start. If an update comes out while games are open, the Console tells you to close everything and relaunch when convenient.
• Applies to the **Default** launcher (Bloxstrap and the others manage their own updates).

### 🔒 Kill All Roblox: locked accounts really stay open
• **Bug fixed:** when many accounts were opened at the same moment, Kill All could sometimes close a locked account.
• **Why:** windows were matched to accounts by guessing from start times. With many windows starting within a second, the guess could swap accounts.
• **Now:** each window is matched by the launch ID the app gave it, or by the Roblox log file it actually has open. Guessing is only used when it can't be wrong.
• **When in doubt, it's kept:** if a window can't be identified for sure while you have locked accounts, Kill All leaves it open. The button shows e.g. **"Killed 14 · 2 locked · 1 unknown"**. Press Kill All again within 5 seconds to close the unknown one too.

### 📊 Whole-PC RAM and CPU above the account list
• The line next to "Account List" now shows the whole computer, like Task Manager: **"4 running · RAM 11.2 / 16 GB (70%) · CPU 23%"**.
• It updates every 2 seconds and turns **orange** when RAM is at 85% or more, or CPU at 90% or more.
• It works even with the per-account RAM display off. Turn it on or off in Performance → RAM usage → **Show PC RAM and CPU usage**.
• The RAM used by just your Roblox accounts is still shown when you hover over that line.

### 🩺 Ban Check is now Account Health
• Renamed to **Account Health**, with a new icon, since it checks more than bans: Banned, Terminated, Locked / signed out, Needs verification, and OK.
• **Tick by status:** new buttons above the list, e.g. **Banned (3)**, **Locked / signed out (5)**. Click one to tick every account with that status, and click again to untick them. You can mix statuses.
• There's **no button for OK accounts**, and OK accounts have no tick box, so they can't be deleted by accident.

### ⬆️ Updates are now required
• When a new version is out, the update window **downloads it right away** and the app restarts on the new version.
• "Manual Download" and "Later" are gone, and the window can't be closed to keep using an old version (closing it quits the app).
• If the download fails (for example, no internet), the window shows **Retry**. Press it once you're back online.
• The app now checks for updates on every start (the "Check for Updates on Startup" switch was removed).
• Note: this starts with v2.10.0. Updating to v2.10.0 itself still shows the old window one last time.

### ⚡ Updating
• Coming from v2.9.9, the app downloads a **small patch** instead of the whole exe. If the patch can't be used, it falls back to the full download automatically.
