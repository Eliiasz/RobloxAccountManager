## 🛠️ What's fixed in v2.9.5

### 🖼️ Taskbar icon
• Fixed: the taskbar showed a blank window icon instead of the ANAne logo.
• The app now sets its icon directly from the ANAne logo in every size Windows uses (taskbar, title bar, Alt+Tab, system tray), and the .exe icon file was rebuilt in the classic format Windows reads everywhere.

💡 If you still see the blank icon after updating, Windows is showing an old cached copy: unpin the app from the taskbar and pin it again (or restart your PC).
