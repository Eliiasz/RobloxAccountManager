## 🛠️ What's fixed in v2.9.4

### 📦 Batch Queue works with every join
Before, only **Join Place ID** and **Roblox Home** used the Batch Queue. Now these do too:
• **Join User** (the box and V → Join User)
• **V → Job ID**
• **V → Small Server**
How it works: turn on **Enable Batch Queue** (Multi Roblox page) and set **Accounts per batch**. Select your accounts and press any join button. Only the first batch opens. When every window of that batch is closed, the next batch opens by itself.
• **Join User:** each batch looks up where the player is at that moment, so if they changed servers, the next batch follows them.
• **Small Server:** each batch looks for a small server again, in case the last one filled up.
• The Console shows e.g. "Batch queue: 20 accounts in 4 batches of 5" when a queue starts.

### ⚡ Smoother account list
• **Lock / Unlock** is now instant: only the 🔒 on the changed accounts appears or disappears. No more freeze.
• **Edit Note** updates just that account's row.
• **Move to Group** no longer rebuilds the whole list.
• Your selection and scroll position stay where they were, and saving happens in the background.
