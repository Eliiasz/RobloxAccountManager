## ⚡ What's new in v2.9.6

### 📦 Faster, smaller updates
Updates no longer have to download the whole app (~79 MB) every time.
• Each new release now also comes with a small **patch** made from the version before it (usually under 1 MB).
• When you press **Update**, the app downloads only that patch and builds the new version from the one you already have.
• Before installing, it checks the result against the official release checksum. If anything doesn't match, or you skipped a version, it simply downloads the full app like before, so updating can never leave you with a broken app.
• The Console shows whether a patch or the full download was used.

ℹ️ This update itself is still a full download, because older versions don't know about patches yet. From the **next** update on, you'll get the small patch.
