## 🛠️ What's new in v2.9.8

### 📐 Tidier Settings
• Settings now use a fixed-width column, so each value box (Launch Delay, Cookie Check Delay, Log Files to Keep…) sits right next to its label instead of at the far edge of a wide window.

### 🧪 Account Creator: Stop closes the windows
• Pressing **Stop** now also **closes every signup browser window** the creator opened.
• Accounts that already finished signing up are kept; signups still in progress are abandoned.
• The results window counts those as **stopped**, not failed (e.g. "Stopped. 12 created · 3 stopped · 5 not started").

### 🦁 Brave is the default browser
• Logins, Quick Sign-in and the Account Creator now use **Brave** by default.
• If you already picked a browser in Settings → Misc → Browser Engine, your choice is kept.
• If Brave isn't installed, the app falls back to Chrome, then Edge, so logins keep working.
